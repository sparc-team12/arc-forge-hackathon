Starting Issue Tracker

The app is two separate servers — a backend API and a frontend — that both need to stay running. Open two terminal windows and start each one below, then open the app in your browser.

1

Start the backend

In a terminal, go to the backend folder and start it:

> cd application\issue-tracker\mcp-issue-tracker\backend
> npm run dev

First time only, if there's no node_modules folder yet: run npm install first.

Ready when the log shows Server listening at http://127.0.0.1:3000
2

Start the frontend

In a second terminal, go to the frontend folder and start it:

> cd application\issue-tracker\mcp-issue-tracker\frontend
> npm run dev

Same first-time note: run npm install first if node_modules is missing.

Ready when the log shows Local: http://localhost:5173/
3

Open it in your browser

http://localhost:5173
